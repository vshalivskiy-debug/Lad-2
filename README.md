# Практична робота №2

## Тема
Інструменти візуальної розробки додатків.

## Мета роботи
Ознайомитися з інструментами візуальної розробки додатків та навчитися створювати графічний інтерфейс користувача у Windows Forms мовою C#.

## Завдання
Створити програму для знаходження суми двох чисел.

Користувач вводить два числа у відповідні поля, після чого програма обчислює їх суму та виводить отриманий результат.

## Виконання роботи
У середовищі Microsoft Visual Studio було створено Windows Forms застосунок мовою C#.

Для створення інтерфейсу програми використано компоненти:

- Label — для відображення текстової інформації;
- TextBox — для введення двох чисел;
- Button — для запуску обчислення.

Після натискання кнопки «Обчислити» програма отримує значення з полів TextBox, перетворює їх у числовий тип, виконує операцію додавання та виводить результат на форму.

## Використані технології
- C#
- Windows Forms
- Microsoft Visual Studio
- Git
- GitHub

## Результат
Створено програму з графічним інтерфейсом, яка дозволяє користувачу ввести два числа та отримати їх суму.

## Висновок
Під час виконання практичної роботи №2 було отримано практичні навички роботи з інструментами візуальної розробки додатків. Було створено інтерфейс Windows Forms та реалізовано введення даних, виконання обчислення і виведення результату.
